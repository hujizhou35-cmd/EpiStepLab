# 暴露、结局与派生指标的来源核查

EpiStepLab v1.1.0。开始研究、接手已有项目、指标定义不清、发现不同版本或准备修改计算方法时阅读。使用前与其他 AI 讨论有助于理清想法；不要求证明已经讨论过，也不把 AI 的回答当作指标依据。技能仍须查原始来源并核对本地字段。

## 先分清名称和构念

先问暴露与结局分别代表什么、哪个版本、测量时间和适用人群、为什么选它们。区分单个原始测量、诊断规则、量表、多个分量组合的指数、经验证的代理指标与新探索评分。缩写相同不代表同一个指标，“认知障碍”“认知得分”和某测试分数也不能自动互换。

不清楚的内容可以先检索和列出候选解释；影响计算、人群或研究意义的问题立即追问。不要为了形成可运行脚本，先猜分量、阈值、单位、缺失规则或权重。

## 从原始定义到实际应用

1. 优先找提出指标的原始定义或原始验证研究、正式量表/算法说明及其补充材料；疾病定义同时查适用的官方/专业标准与版本。原始文献找不到时如实说明，不把最新一篇应用论文称为原始定义。
2. 比较通常 3–5 篇最相关的实际应用原始研究，关注人群、数据库、测量版本、公式、分组和缺失处理差异。不足时记下检索范围和实际数量；引用链里的二次转述继续往原文追溯。
3. 记录全文和补充材料是否实际取得。仅摘要不够核实公式时标“未核实”，不能根据标题、AI 回答或相似指标补出细节。按 [最新方法检索](method-discovery.md) 保存实际检索式和访问记录。
4. 把原始定义与本地版本问卷、字典和实际列逐项对应。文献说明研究者怎样构造指标，数据库官方文档说明字段实际代表什么，两者需要同时核实。

PubMed 的 PMID 是稳定标识，可配合 DOI、原文链接和 Search Details 留痕；并非所有来源都有 PMID。无 PMID 时记录真实可用的 DOI、官方标准编号、注册号、版本文件网址或其他稳定标识，不编造编号。[PubMed 官方帮助](https://pubmed.ncbi.nlm.nih.gov/help/)

## 形成一份可复核的指标说明

研究方案可以只保留摘要，详细说明单独保存，至少包含：

| 项目 | 需要说清楚什么 |
|---|---|
| 身份与版本 | 指标名称/全称、构念、原始或修订版、语言/人群、测量时间；是否已经验证 |
| 原始证据 | 原始定义及验证来源、PMID/DOI等标识、原文与补充材料链接、访问层级和日期、对应页/节/表/公式位置 |
| 分量与公式 | 每项分量、原始单位、转换及校正、计分方向、加权/求和/标准化公式、顺序、理论范围和解释 |
| 分类规则 | 连续值与分类的关系、阈值及适用范围、边界归属、分组依据；样本分位数与临床阈值不能混称 |
| 缺失与覆盖 | 分量缺失、拒答、不适用、未测量、检测限、代理回答如何处理；是否允许部分计分及分母怎样变化 |
| 本地字段 | 数据库/版本/波次/模块/文件、实际字段名/类型/单位、跳转与测量资格、连接键和对应关系 |
| 应用比较 | 几篇实际应用是否沿用原始定义、是否删分量/换代理/改阈值，为什么不同；对本研究能否照搬 |
| 决策与未决事项 | 本研究拟采用哪个明确定义、与原定义的偏离、理由、待核实处、使用者确认原话/来源和日期 |

若来源没有页码，可记录章节标题、表号、公式编号或稳定文件位置；原文没写清就明确写“原文未交代”。不能编造可复核位置。

## 常见冲突怎样处理

- **单位和标准化基准不同：** 核对原始值、转换系数与参照均值/标准差来自外部标准还是本样本；性别、年龄或周期内标准化会改变比较含义，需讨论。
- **缺少分量或只有代理：** 先报告字段覆盖限制，讨论补充来源、改研究问题或明确命名为修改/代理指标。少一个分量不等于该分量为零；不直接称为标准原指标。
- **阈值或公式版本冲突：** 保留每个来源及位置，说明对人数和含义可能的影响，作者确认后再派生。合理替代定义可讨论为敏感性分析，不挑显著版本。
- **结局与暴露成分重叠：** 查是否出现同一测量同时构成暴露和结局、数学耦合、循环定义或时间泄漏；先讨论研究问题是否仍成立。
- **数据驱动权重或新评分：** 区分原有公式与本研究重新估计。若用于预测，权重/标准化/选择在训练或相应重采样内学习，验证数据不能参与；若宣称测量效度，需另作适用的验证设计。
- **已有结果无生成代码：** 暂记来源不明，保留原文件；不能根据分数分布反推公式后称已核实。

## 确认后的当前步骤才写代码

向作者解释采用版本、所需变量是否齐备、仍有的限制与可选方案。待本步定义和执行范围确认后，才在当前编号目录写普通 R 派生代码；用 `【已确认】` 注明参数依据，保存本步完整输入和指标说明。

按分量检查特殊编码、单位、分母、边界与合理范围，并用少量明确标记的人工可核对示例或模拟值核对计算；真实数据仍需保存人数、覆盖和缺失汇总。未知值不能默认为阴性或零，未测量人群不能混进有测量覆盖的分母。保存派生代码、正式输出与校验信息，后续定义改变时标记受影响结果需要复核，停止自动覆盖下游。

技术计算正确不等于指标在新数据库/人群具有原有效度；原始指标来源核实、实际字段可构造、算法实现通过检查及科学解释成立分别汇报。指标定义的核查不等于后续全部分析已获准执行。

本参考中检索官方说明核查日期：2026-10-17；每个具体研究指标仍需自己的实际检索与确认记录。
