# 按研究问题选择方法

EpiStepLab v1.1.0。需要选择、比较或调整方法时阅读。旧项目和下面的例子都是查找入口，不构成可用方法的上限，也不要求把每一种方法都做一遍。

## 先说清问题，再考虑工具

先用一句普通话说明希望得到什么：描述分布、描述两项指标的关系、把许多变量压缩成少数维度、寻找人群模式、估计关联、描述变化、回答因果问题，还是预测未来。再核对人群、时间、变量类型、缺失、抽样设计、重复测量及可用信息量。方法名称不能替代研究目标。

按 [最新方法检索](method-discovery.md) 查近期进展与基础方法。每个真正可行的候选方案都应说明：

| 比较项目 | 用直白语言回答 |
|---|---|
| 目的与结果 | 回答哪个问题？最终给出什么数量或图？ |
| 数据要求 | 需要哪些变量、测量时点、样本或事件信息？本地实际具备吗？ |
| 假设与适用性 | 有哪些不能只靠软件检验的前提？适合当前抽样、家庭、中心或纵向结构吗？ |
| 解释边界 | 能说明关联、模式、预测还是因果？哪些话不能由它得出？ |
| 检查与验证 | 如何发现不收敛、失配、不稳定、泄漏及不可估？ |
| 增益与代价 | 相比更简单方案增加什么信息？需要多少计算、依赖和额外决定？ |
| 决策 | 推荐、备选、暂不采用还是证据不足？理由、文献与作者确认在哪里？ |

可以建议暂不使用某方法。例如仅研究一个已有指标与结局的关联，PCA 未必增加价值；没有分群目的和稳定性验证条件，聚类不必加入。相反，需要研究饮食模式或多指标结构时，不能因为旧流程只有回归便忽略降维。优先普通、可读、可独立运行的 R；确需其他实现时先解释必要性与交付影响，和使用者确认。

## 方法家族：用于发现选择，不能直接套参数

| 目标 | 可以调查的方法 | 优先澄清的区别 |
|---|---|---|
| 描述相关结构 | Pearson、Spearman、Kendall、偏相关、适用的调查设计或重复测量相关方法 | 线性与单调关系、变量尺度、调整目标、依赖结构、有效分母与多重比较 |
| 降维与指标结构 | PCA、因子分析、对应分析、多重对应分析、混合数据因子方法 | 压缩总变异与测量潜在构念不同；连续、分类、混合或有序变量不能直接当成同一种输入 |
| 发现分群或模式 | K-means、层次聚类、PAM、模型聚类、潜在类别/潜在剖面、适用的密度方法 | 距离、分布或局部独立假设；是否允许无明确分群、噪声点和类别不确定性 |
| 估计关联与非线性 | 广义线性模型、GAM、样条、稳健回归、分位数回归、适用的贝叶斯模型 | 结局类型、效应尺度、条件均值与条件分位数、函数形式、先验、设计适用性 |
| 重复测量和变化 | 混合模型、GEE、纵向轨迹、联合模型、适用的生存/竞争风险/多状态方法 | 个体条件效应与人群平均效应；时间原点、重复记录、失访、事件和时间顺序 |
| 回答因果问题 | DAG、标准化、倾向评分、加权、双重稳健估计及适用的目标试验模拟 | 先明确干预与比较、时间顺序、识别假设、重叠及混杂控制；算法不能补出未测量信息 |
| 预测和复杂输入 | 正则化、树模型、集成学习及适用的新预测方法 | 预测对象与窗口；训练内预处理、调参、校准、内部/外部验证与部署时可用信息 |
| 特殊数据结构 | 成分数据方法、计数/零膨胀模型、空间方法、功能型或时间序列方法等 | 是否有总和约束、额外零机制、空间/时间相关性；先查主题和原始测量结构 |

这张表没有列出的新方法，也应根据目标继续查原始论文、作者代码和官方文档。先核实它解决的具体问题、适用条件、成熟度、验证证据和可读实现，再提出选择；不用“未列入指南”作为拒绝理由。方法支持范围与已经实测的范围分别报告。

## 相关性：Spearman 等方法的讨论卡

先确认要描述哪些配对关系、连续或有序变量怎样编码、是否确有单调目标、缺失按共同样本还是逐对处理，以及是否要检验、区间和多重比较校正。偏相关中调整哪些变量及其目的另行确认；给无序类别编号码不会使其具有真实顺序。

记录每对变量有效人数、并列秩、常量/全缺失与所用样本。Spearman 是秩之间的相关；缺失处理可能改变参与排序的人群，逐对删除还可能得到非半正定的相关矩阵，不能直接把它当作可靠 PCA 输入。[R `cor` 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.html)

检验方式与并列值、样本量和设计相匹配。不能把 `exact = TRUE` 一概称为精确检验；有并列值时核对警告和可用近似。`cor.test` 的常规区间只针对 Pearson，Spearman 区间需另选有依据的方法及重采样单位，不能把 Pearson 区间改个名称后使用。[R `cor.test` 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cor.test.html)

普通 `cor.test` 不处理调查分层/PSU、家庭或重复测量。复杂调查中的加权秩定义、目标相关量和设计方差方法需要专门核查；不能把权重列复制进普通检验或忽略设计后宣称全国推断。依赖样本的置换/自助法也不能随意按独立行打乱。相关不表示因果，也不能用零相关排除非单调关系。

## 降维：PCA 与因子方法的讨论卡

先决定压缩哪些变量、每个变量为何纳入、变换/中心化/标准化、缺失方案、保留维数依据和后续使用目的。不同单位或方差大小会影响 PCA；不固定“累计达到某百分比”或“特征值大于 1”为所有研究的规则。分类或混合数据先调查合适的方法，参见 [FactoMineR 作者方法论文](https://www.jstatsoft.org/article/view/v025i01)；软件支持某数据类型不等于适合本研究测量目标。

检查零方差列、完全线性依赖、有效矩阵秩及高维小样本的不稳定性；常量变量不能直接做单位方差缩放。保存变量顺序、中心/尺度、载荷、得分、全部方差分母、保留维数和模型对象。用正式对象核对得分和重构；截断保留成分后不能把剩余方差重新归一化就宣称解释了原数据 100%。主成分整体符号可以翻转；特征值相同或接近时还要比较对应子空间与重构，不能仅凭逐列符号或数值不同判失败。[R `prcomp` 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/prcomp.html)

PCA 压缩变量，聚类分组观察对象，两者目的不同。PCA 载荷不自动具有原有临床量表效度；若据此新建指标，按 [指标溯源](indicator-provenance.md) 区分原指标与新探索指标。用于预测时，缩放、载荷和成分选择只能从相应训练折学习，再用于验证数据。

## 聚类与潜在分型的讨论卡

先讨论分谁、用哪些特征、距离/分布与缩放、缺失和极值、是否排除结局信息、候选分群数量及确定依据、随机初始化、稳定性/外部检验和资源预算。不要为了分群后结局显著反复挑特征、K 或算法；把结局放进聚类再检验该结局差异有循环解释风险。

- K-means 基于数值空间的组内平方距离，受尺度与初始中心影响。确认算法、随机种子和多次起点；检查收敛、组大小、中心和平方和。类别编号没有自然次序，验证时比较同群关系或匹配后的分组。[R `kmeans` 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/kmeans.html)
- 层次聚类需要明确距离及连接方法；`ward.D` 和 `ward.D2` 不等同。Ward 类方法要核查与欧氏几何的相容性，不能给任意距离随手套 Ward；树的左右叶序也不代表实质分组不同。[R `hclust` 官方说明](https://www.stat.ethz.ch/R-manual/R-devel/library/stats/html/hclust.html)
- 混合变量可调查 Gower 等距离，先核对有序、无序、对称/非对称二元类型与变量权重。`daisy` 的变量权重不是抽样权重，不能据此宣称调查设计已处理。[`cluster::daisy` 作者文档](https://stat.ethz.ch/R-manual/R-devel/library/cluster/html/daisy.html)
- 模型聚类、潜在类别和潜在剖面分析另查分布、局部独立等假设、局部最优、模型可识别性和分类不确定性；不能只按一个信息准则就命名“疾病亚型”。

结合分离度、组大小、临床可解释性、不同起点/合理扰动/适当重采样和独立数据评价，允许报告“没有可靠分群证据”。稳定性重采样单位须符合人/家庭/中心结构；把预处理和分群重做哪些部分说清楚，不能只重复固定标签得到稳定结论。稳定不等于真实疾病类别，依据见 [fpc 作者手册中 `clusterboot`](https://cran.r-project.org/web/packages/fpc/fpc.pdf)。UMAP/t-SNE 等低维图可用于探索，但图上分开不等于原空间存在可重复类别。距离矩阵可能随样本量平方增长，先检查内存和资源。

## 其他方法同样要核实的关键点

因果分析先画明变量时间及关系、明确目标效应，再讨论一致性、可交换性、正值性等识别条件和敏感性分析。双重稳健、交叉拟合或机器学习估计不取消这些条件；一部分模型条件满足也不能纠正所有测量误差和未测量混杂。方法调查可从作者的 [Causal Inference: What If](https://miguelhernan.org/whatifbook) 追溯，不能把预测性能当因果识别。

纵向、混合模型、GEE 和生存方法需核查时间轴、依赖、失访和估计目标；成分数据需核查总和约束、零值与变换依据，不能直接将所有比例当独立暴露，也不能默认加伪计数。具体设定与检查按原始方法资料及 [现有分析讨论卡](analysis-decisions.md) 展开。新方法同样服从完整输入、新 R 会话、正式对象导出、图表实看和失败留痕规则。

MR 仍不纳入。BKMR、大规模聚类/重采样、复杂贝叶斯或其他可能长时间运行/需要服务器的方法，先准备当前已确认范围的材料，说明资源与未知项并停下，等待明确执行决定；方法名较普通也不能绕过这条规则。每个方法都在对应步骤与作者确认，路线讨论不生成后续整套脚本。
