# 数据来源与字段核查

在新项目准备、接手旧项目、换数据库或换数据版本时阅读。本文件提供核查办法，不是任何数据库的完整字段字典。官方入口核查日期：2026-10-17；实际研究时仍须打开对应版本资料复核。

## 先确认手里到底是什么

1. 只读查看工作目录中的数据、压缩包、说明、字段表、代码和已有结果。记录文件路径、大小、格式、版本或发布日期、调查周期、来源网址或使用者提供的来源。不要运行旧脚本来“试一下”。
2. 区分原始发布文件、官方派生数据、第三方协调数据、研究者加工数据和演示或合成数据。名称相似不代表内容或版本相同。记录已有输入的校验信息；后续脚本和结果另行记录版本。
3. 检查所需模块是否真正存在、能否读取、是否包含目标人群和周期。文件夹里有数据库名称不等于所需字段可用。
4. 资料不足时，先请使用者说明最少的目标：数据库、预计人群、暴露和结局大意，以便查对模块。完整研究设计留到数据来源与基本结构可行后讨论。
5. 没有可用数据时，立即提出具体选择：使用者下载到本地、提供现有位置，或核实后采用在线平台。说明每种方式实际能做什么；未确认来源前停止数据分析代码。账号、许可、在线环境或远程算力不能凭空假设。

接手旧项目时，把已有步骤标为“可复用”“需复核”“来源不明”或“仅有结果无生成代码”，记录依据。保留历史文件，避免把一次成功运行直接当成科学定义正确。

## 建立实际字段对照

先读本地字典和发布说明，再查该版本官方问卷、数据字典与分析指南；研究论文用于解释研究定义，不能代替原字段说明。官方资料冲突、无法访问或本地标签与官方说明不一致时，写明冲突并立即追问，不自行选一个解释。

每个需要使用的字段至少记录：

| 项目 | 应记录的内容 |
|---|---|
| 来源 | 数据库、版本/周期、模块、文件名、官方文档链接与查阅日期 |
| 原始信息 | 实际变量名、标签、类型、单位、编码及取值范围 |
| 调查范围 | 年龄/性别等适用条件、抽取子样本、问卷跳转、是否代理回答 |
| 缺失 | 拒答、不知道、未测量、不适用、失访、检测限等编码和含义 |
| 时间与连接 | 测量时间、个体/家庭/访问标识、周期或波次、预期连接关系 |
| 分析安排 | 原始变量或派生变量、拟采用定义、依据、尚待确认问题 |
| 设计信息 | 权重类型与适用范围、分层/聚类/重复权重、纵向或链接资格 |

对照表必须和实际文件逐项核对：字段是否存在、类型能否表达编码、频数与范围是否合理。未知编码不要通过强制转数值、填零或统一 `na.omit()` 隐藏。

疾病、饮食或认知指标由多个分量构造时，另列公式、每个分量的来源、单位和缺失规则。某周期没有测量一个分量，不等于该分量为阴性；一个同名代理指标不能默认为原构念。

## NHANES：主要样板，按周期复核

从 [CDC 变量检索](https://wwwn.cdc.gov/nchs/nhanes/search/default.aspx) 找到对应周期和模块，再阅读数据旁的完整文档。检索页本身有覆盖限制，不能据一次零结果认定变量从未测量。

- 对每个模块核实连接键、适用年龄、检查/实验室子样本、检测方法与单位、检测限、问卷跳转和修订说明。不同周期同名字段也要检查可比性。
- 先确定本研究实际使用的全部测量，再选择能覆盖其共同适用样本的权重及设计变量。不能只因所有字段都有值就认为样本可合并；有些子样本彼此不重叠。按 [CDC 抽样设计教程](https://wwwn.cdc.gov/nchs/nhanes/tutorials/SampleDesign.aspx) 和 [权重教程](https://wwwn.cdc.gov/nchs/nhanes/tutorials/weighting.aspx) 核实。
- 跨周期合并要核查发布时期长度、重叠参与者、测量变动及适用权重。不要内置“所有权重除以周期数”的通用规则。2017–March 2020 是特殊的疫情前发布时期，不能与其已包含的 2017–2018 再拼接；具体处理查 [该时期官方分析说明](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/overviewBrief.aspx?Cycle=2017-2020)。
- 饮食回顾、空腹、生物标志物和环境暴露等按实际文件文档确定分析条件；不预填所有项目通用的有效天数、校正方式、阈值或权重字段。
- 若涉及死亡随访，单独核实链接版本、资格、截止时间与公开文件限制，不能从横断面主表推断死亡状态。

研究启动时还应查 [NHANES 分析指南目录](https://wwwn.cdc.gov/nchs/nhanes/analyticguidelines.aspx) 的最新、适用说明，记录采用了哪一份。

## 老年纵向数据库：按实际版本建立规则

| 数据库与官方入口 | 必须另行核实的差异 |
|---|---|
| [CHARLS 基线资料入口](https://charls.pku.edu.cn/en/Data/a2011_CHARLS_Wave1__Baseline_.htm)、[2018 用户指南](https://charls.pku.edu.cn/en/data/User2018.pdf) | 个人与家庭标识、配偶/代理/部分访问、补样和追访状态、各模块时间、横断面与纵向目标所需权重。2018 指南中的横断面权重安排不能推广为所有波次都有同一种纵向权重。 |
| [北京大学 CLHLS/CLHLS-HF 资料库](https://opendata.pku.edu.cn/dataverse/CHADS)、[ICPSR CLHLS 系列](https://www.icpsr.umich.edu/web/DSDR/series/487/studies) | 所用产品是横断面、纵向还是特殊子样本；存活/死亡问卷、失访、替补样本、年龄与调查日期、标识连接、权重及发布版本。两处发布产品不能仅凭名称当成相同数据。 |
| [ELSA 获取入口](https://www.elsa-project.ac.uk/accessing-elsa-data)、[用户指南](https://www.elsa-project.ac.uk/user-guides)、[调查文档](https://www.elsa-project.ac.uk/study-documentation) | 主访、自填、护士/健康访问、营养和派生模块的适用波次、样本与权重；同一人不同模块是否都有资格和记录；原始与 harmonised 产品的差异；家庭关系、失访和刷新样本。 |

ELSA 的常规归档资料与行政链接资料获取条件不同；其官方获取页说明链接 HES、死亡和癌症资料需另走适用渠道。因此，“已有 ELSA 数据”不足以确认能够做这些链接结局，必须核对实际持有文件和当前权限。

任何其他数据库同样从官方发布入口、具体版本字典、调查设计和实际文件建立对照；不借用 NHANES 字段名或规则填补空白。

## 进入下一阶段前汇报

用直白语言列出：已找到哪些数据、能做哪些目标、关键字段是否核实、仍缺哪些资料，以及需要使用者回答的具体问题。资料未解决的目标标为待定。确认来源和基础结构后进入研究设计讨论，不能把核查过程中发现的变量组合自动变成研究方案。
