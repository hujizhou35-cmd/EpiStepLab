# 方法检索与比较

按研究主题保留本次实际检索和选法证据。方法可以不用，但应知道它回答什么问题、何时适用及为什么不采用。此文件不提供预先选好的分析套餐。

## 本次检索

- 日期、主题、当前研究目的与方案版本：待填写
- 场景：初次启动 / 接续（按实际填写）
- 上次检索日期与记录位置：首次填写不适用，接续填写实际记录
- 时间范围：初次默认近三年进展并追溯基础方法；接续补查上次以来变化
- 数据结构：数据库/版本、抽样设计、随访或聚类层级、变量类型及样本限制：待核实

| 渠道/数据库 | 实际检索式与日期限制 | 检索日期 | 覆盖内容与结果获取范围 | 限制/未完成内容 |

检索包括相关原始研究、方法论文、作者 GitHub 仓库和官方软件文档。没有找到或无法访问均如实记载；联网失败不能写成已完成最新检索。主题尚不清楚时先追问。

## 候选方案比较

每个方案可用短段落填写以下内容，避免为了填满表格编造资料。

- 要回答的具体问题、结果怎样解释：待填写
- 所需变量、样本信息与本地可行性：待核实
- 主要假设，是否适合本研究的抽样设计、时间关系和纵向/重复测量结构：待核实
- 对照的成熟或简单方案，以及新方法增加的实际价值：待填写
- 需要的诊断、稳定性或外部验证、偏差控制和敏感性分析：待讨论
- 数据处理、依赖、计算资源与解释成本：待核实
- 推荐或不推荐及理由；无法判断的事项：待填写
- 属于主要分析还是探索分析：待讨论

PCA 用于压缩或探索变量结构，聚类用于探索样本分群；是否需要取决于研究问题。探索结构不能直接解释为疾病机制或可靠临床分型。未列出的方法继续查原始证据，不受旧工作流限制。不因结果不显著不断增加方法。
