# 工作习惯与来源

[English](README.md) | **简体中文**

作者以往手工分析的有用习惯：每步保存普通 R 代码、完整实际输入、输出、检查和说明；按真实研究安排步骤；修改上游后重新检查依赖。公开总结不包含历史课题名称、具体研究组合或未发表结果。

运行文件来自各自独立版本，按原始字节复制；根 README、双语教程、许可、Plugin 元数据和公开报告是本次发布整理新增，不冒充原版内容。公开报告保留失败与访问限制，原始对话、日志、私有路径和完整历史存档留在本地。

自有内容采用 MIT。论文、数据库、R 与相关包继续受各自条款约束；本项目主要链接官方说明和研究来源，没有重新授权其全文、数据或软件。R 模板是本项目源码；未捆绑第三方 R 库。原创工作图和图标使用 MIT。公开模拟示例没有真实个人数据。

文件对应：[v1.0.0 运行清单](runtime-v1.0.0.json)、[v1.1.0 运行清单](runtime-v1.1.0.json)、[公开派生材料对应表](public-materials.json)。清单记录相对来源、哈希和整理原因；真实机器路径仅留本地。

页面组织参考 PaperQA、targets、Scientific Agent Skills 及作者已有项目的快速开始、完整中文页和精简附件习惯。未复制其统计规则、效果数字或授权范围。外部格式依据见安装页。
