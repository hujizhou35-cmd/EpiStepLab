# Working habits and provenance

[English](README.md) | [简体中文](README.zh-CN.md)

The author's manual workflow kept readable R code, complete actual inputs, outputs, checks and notes together for each step; arranged steps for the actual question; and revisited dependencies after upstream changes. This anonymous account excludes historical topic names, specific unpublished study combinations, and results.

Runtime files are copied byte-for-byte from their own independent versions. The root README, bilingual guides, license, plugin metadata, and public reports are publication additions, not original version content. Public reports retain failures and access limitations; original conversations, logs, private paths and complete historical archives remain local.

Original project content uses MIT. Papers, databases, R and packages retain their own terms; linking them does not relicense their texts, data or software. R templates are project source; third-party R libraries are not bundled. Original workflow artwork and the icon use MIT. Public examples contain only simulated data.

Mappings: [v1.0.0 runtime](runtime-v1.0.0.json), [v1.1.0 runtime](runtime-v1.1.0.json), [public derived materials](public-materials.json). They record relative sources, hashes and curation reasons. Actual machine paths remain local.

Page organization draws on PaperQA, targets, Scientific Agent Skills, and the author's existing projects for quick starts, complete Chinese pages and concise downloads. Their statistics, performance claims and execution permissions are not inherited. See installation guides for official format references.
