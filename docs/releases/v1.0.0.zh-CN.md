## 本版内容

发布原始的逐步确认、完整输入、独立 R 会话与结果复核工作方式。

运行文件来自本版保留源，不由另一版本重建。双语公开文档、MIT 文件和插件元数据是明确标识的发布新增材料。[来源清单](https://github.com/hujizhou35-cmd/EpiStepLab/blob/v1.0.0/docs/provenance/runtime-v1.0.0.json)

## 验证与限制

既有记录：17 个模拟进程场景、9 类 AI 行为演练，并针对遗漏敏感性分析提醒进行了复测。 这些是技术检查与行为演练，不是独立医学研究。[完整报告、失败与限制](https://github.com/hujizhou35-cmd/EpiStepLab/blob/v1.0.0/docs/validation/v1.0.0/report.zh-CN.md)

原技术环境为 Windows 11、R 4.4.2。宿主提供文件读取、R、联网检索与实际看图能力。技能资源仍为中文。真实数据库研究、科学有效性、发表条件、自动触发及全面平台/系统/英文兼容尚未建立；正式发布不改变这些限制。总开发耗时和 token 消耗未建立完整统计。
