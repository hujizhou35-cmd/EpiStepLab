## This version

Preserves the original step-confirmation workflow, complete inputs, independent R sessions, and result checking.

Original runtime bytes come from this version's preserved source, not a reconstruction from another version. Publication documents, the MIT file, and plugin metadata are identified additions. [Source manifest](https://github.com/hujizhou35-cmd/EpiStepLab/blob/v1.0.0/docs/provenance/runtime-v1.0.0.json)

## Validation and limits

Existing records: 17 synthetic subprocess scenarios and 9 AI behavior scenario types, including a targeted retest after a missing sensitivity-analysis reminder. These are technical checks and behavior rehearsals, not independent medical studies. [Full report, failures and limits](https://github.com/hujizhou35-cmd/EpiStepLab/blob/v1.0.0/docs/validation/v1.0.0/report.md)

Original technical execution used Windows 11 and R 4.4.2. The host supplies file access, R, internet/search, and actual image review. Runtime resources remain Chinese. Real database research, scientific validity, publication readiness, automatic triggering and comprehensive host/OS/English compatibility are not established. A formal release does not change those limits. Total development time and token consumption are not fully established.
