## 实际基线核查及失败保留

24 条模拟记录全部保留，两组各 12 条；年龄有效分母为 11/12，均值 46.6363636363636/58.5，样本 SD 为 3.74893924391226/3.60555127546399。年龄和性别缺失未插补、未删人。CSV 读回后与独立求和、平方差计算一致。

移动副本在新 R 进程退出 0，4 份 CSV 字节一致。首次包装器因临时环境变量从不存在变为空字符串而恢复自检失败，修正启动器后复核恢复。额外 PNG 严格比较仍退出 1：文件和解码像素都不同，原因未确定。两张实际 PNG 均已查看，底层绘图 CSV 一致；不宣称逐像素复现，不把包装器失败写成成功。

原始 R 环境拒绝含空格临时路径，启动器采用指向工作区的临时盘符，并恢复环境和映射。失败轮次与原始日志保留本地。
