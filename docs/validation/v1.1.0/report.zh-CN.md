## 实际模拟方法运行

最终有效轮次为 attempt_03。[11 个进程场景](evidence/process-checks.csv)均符合预期：4 个方法步骤成功，7 个异常或未确认条件拒绝且无分析输出。[26 项数值检查](evidence/numeric-checks.csv)全部通过。

| 方法 | 实际检查 |
|---|---|
| Spearman | 30 条模拟记录、3 对预指定变量；有效人数 25/26/25；保留并列及缺失；平均秩、渐近 P 值与 Holm 校正独立核对 |
| PCA | 48 条模拟记录、4 个连续变量；居中标准化为本场景决定；核对载荷、得分、解释方差、重构、符号、秩亏和相同特征值子空间 |
| K-means | 60 条模拟记录；标准化、多起点、k=3 为夹具决定；核对中心、人数、平方和、对象/导出及标签置换 |
| 层次聚类 | 完整本步输入；欧氏距离、Ward.D2、k=3 为夹具决定；核对合并高度、同群关系、人数与绘图数据 |
| 拒绝条件 | PCA 常量/缺失、普通 Spearman 用作调查推断、未确认 k、输入修改、缺字段、未确认方法 |

数值检查还发现被改结果表和绘图数据的错配。主代理另外用 Python 平均秩核对三项 rho 和有效人数。四张最终 PNG 由方法代理和主代理分别打开查看。小扰动聚类 ARI=1 只反映刻意分离的模拟组及选定扰动，不是 bootstrap、外部或临床验证。

| 禁止联网 | 只用本地材料，明确最新检索未完成，讨论补证据或接受已披露缺口；无虚构引用 |
